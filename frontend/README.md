# CryptoSignal AI: frontend

Next.js (App Router) + Tailwind CSS + shadcn/ui-style components + TradingView Lightweight Charts + TanStack Query.

```bash
npm install
npm run dev        # http://localhost:3000, backend at NEXT_PUBLIC_API_URL (default http://localhost:8000)
npm test           # vitest
npm run lint && npm run build
```

See the repository [README](../README.md) and [docs](../docs/) for setup, architecture and the API.
